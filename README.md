# 🚀 Guelichweb - Site Web Officiel

Bienvenue sur le dépôt officiel de **Guelichweb**, une solution web moderne, performante et esthétique dédiée aux agences, entrepreneurs et entreprises B2B.

👉 Site officiel : https://guelichweb.online/

Ce projet est construit avec **Next.js 14**, **Sanity CMS**, et **Framer Motion** afin d’offrir une expérience utilisateur fluide et une gestion de contenu optimisée.

---

## ✨ Fonctionnalités

* 🌐 **Multilingue** : Support du Français et de l’Anglais grâce au routage dynamique de Next.js.
* 🎨 **Design Premium** : Interface moderne avec mode sombre et animations fluides via Framer Motion.
* 📝 **CMS intégré** : Gestion simplifiée des contenus (projets, services, blog) avec **Sanity.io**.
* 📧 **Formulaire de contact** : Envoi d’emails fiable via l’API **Resend**.
* 📱 **Responsive Design** : Optimisé pour mobile, tablette et desktop.
* ⚡ **Performance & SEO** : Optimisation avancée pour un chargement rapide et un référencement performant.

---

## 🛠️ Stack Technique

* **Framework** : [Next.js 14](https://nextjs.org/) (App Router)
* **Styling** : [Tailwind CSS](https://tailwindcss.com/)
* **Animations** : [Framer Motion](https://www.framer.com/motion/)
* **CMS** : [Sanity.io](https://www.sanity.io/)
* **Emails** : [Resend](https://resend.com/)
* **Icônes** : Lucide React & React Icons

## 🚀 Installation & Développement

### 1. Cloner le projet

```bash
git clone https://github.com/krissiankg/guelichweb.git
cd guelichweb
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Configurer l'environnement

Copiez le fichier `.env.example` vers `.env.local` et ajoutez vos clés API :

```bash
cp .env.example .env.local
```

---

### 4. Lancer le serveur de développement

```bash
npm run dev
```

Le site sera accessible sur :
👉 https://guelichweb.online

## 🏗️ Déploiement

### 🚀 Déploiement via Vercel (Production)

Le projet est déployé sur **Vercel**, la plateforme recommandée pour les applications Next.js.

## 📝 Structure du projet

* `/app` : Pages et routes API (Next.js App Router)
* `/components` : Composants UI réutilisables
* `/sanity` : Configuration et schémas CMS
* `/dictionaries` : Fichiers de traduction
* `/public` : Assets statiques (images, logo)
